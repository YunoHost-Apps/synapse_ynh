This new update introduces a script to clean-up the database. Use it when using Mautrix Bridges:
- the script is in `__INSTALL_DIR__/synapse_clean_unreferenced_states.bash`
- it runs a prebuilt rust program to find unreferenced state groups https://github.com/erikjohnston/synapse-find-unreferenced-state-groups/pull/8/changes
- it is run by a cron task located in /etc/cron.d/__APP___clean_unreferenced_states
  - you can change the cron schedule from the config panel
  - the cron is deactivated by default: '* * 31 2 *'
  - to run every Monday: '0 0 * * 1'
  - use Cron Syntax https://www.man7.org/linux/man-pages/man5/crontab.5.html"
- before activating the cron, ensure to have the size of synapse DB available as free space
- synapse will be stopped once to find the states, and once to REINDEX the database. The latter can take hours the first time you run it
- running this cleanup can free up to 90% of the database space usage when using Mautrix Bridges
